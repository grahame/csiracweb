CSIRAC
======

Materials for emulating CSIRAC, Australia's first digital computer.

* `csiracem/` — a web emulator (Vite + React + TypeScript), ported from John
  W. Spencer's Turbo Pascal CSIRACEM. See `csiracem/README.md`.
* `turbo/`, `dos-env/`, `freepascal/` — John Spencer's original CSIRACEM
  sources and the DOS environment used to build them.
* `dos-distro/` — his EM2/EM3 Windows distribution, with sample programs and
  data tapes.
* `pdf/` — the CSIRAC programming and Interprogram manuals.

John Spencer kindly provided the code for his CSIRAC emulator, and gave
permission for it to be ported to the web.
