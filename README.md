CSIRAC
======

Materials for emulating CSIRAC, Australia's first digital computer.

* a web emulator (Vite + React + TypeScript), ported from John
  W. Spencer's Turbo Pascal CSIRACEM. See `csiracem/README.md`.
* `docs/csiracem/` — John Spencer's original CSIRACEM sources.
* `docs/pdf/` — the CSIRAC programming and Interprogram manuals.

John Spencer kindly provided the code for his CSIRAC emulator, and gave
permission for it to be ported to the web.
